# InspireX MVP 范围（个人 · 全本地 · 本地 CLIP）

## 定位

个人桌面视觉素材库：采集带出处 → 文件夹/标签整理 → FTS + 颜色 + CLIP 找回 → 拖出应用。

## DoD（本阶段）

- [ ] `./scripts/verify.sh` 退出码 0  
- [ ] `AI_MOCK_MODE=true` 下可导入图片并列表展示  
- [ ] Mock CLIP embedding 写入，支持以文搜图（伪向量相似度）  
- [ ] SQLite FTS 可按文件名检索  
- [ ] 文件夹/标签整理（虚拟文件夹：勾选后点旁 + 放入，不复制原文件）  
- [ ] `start.sh` / `stop.sh` 对称  

## 非目标（本阶段）

云同步、团队协作、移动端、真实 CLIP 权重下载（仅 Mock）、浏览器插件。

## 数据流

```
外置卷 / 本地库 / 中转站 → 链接浏览原文件（不复制进库）
订阅 / 插件 / AI 生图 → 入库目录 → 缩略图 / CLIP
「全部素材」= 入库项 ∪ 各来源链接图
```

中转站绑定用户已有的云同步文件夹（iCloud 等），多端共享由云盘完成，见 `ADR/005-hub-cloud-folder.md`。
