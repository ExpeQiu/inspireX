# 复用系统相册归类

## 用法

1. 本机库绑定 `~/Pictures` 或直接绑定 `Photos Library.photoslibrary`
2. 打开「照片」条目后，侧栏出现 **人物 / 地点**（来自系统已分析数据）
3. 若提示无法读取：系统设置 → 隐私与安全性 → **完全磁盘访问** → 勾选 InspireX / 终端

## 能力边界

| 有 | 无 |
|----|----|
| 已命名人物筛选 | 调用系统 ML 对新图即时分析 |
| GPS→城市地点筛选 | 完整场景 labels（后续可加） |
| 列表项带 people/place 元数据 | 外置盘 / 订阅图自动获得系统归类 |
