# 中转站（云同步文件夹）

侧栏「本地库」下方的 **中转站**：绑定一个本机已有的云盘目录，存入的图片由云盘同步到其他设备。

## 用法

1. 点「中转站」→「选择文件夹」，或一键「使用 iCloud 云盘」。
2. 建议目录：`iCloud 云盘/InspireX-Hub`（各端绑同一相对位置）。
3. 「存入」或拖入图片；也可在外置卷/本地库勾选后点「复制到中转站」。
4. 另一台电脑打开灵犀，把中转站绑到该云盘在本机的对应路径。

## 边界

- 灵犀 **不** 做账号、上传、冲突合并。
- 中转站文件 **不** 复制进 `~/InspireX/Library`。
- 云盘「优化存储」时，未下载的原片可能暂时看不到。

## 配置

- 应用内绑定（写入 `~/InspireX/hub-root`）
- 或环境变量 `INSPIREX_HUB_ROOT`

## 日志

`hub_bind path=`、`hub_copy src= dest=`（`target=inspirex`）
