## 来源二：订阅 / 网页图片

### 目标

用户登记一个「源」，按间隔拉取**新增公开图片 URL**，去重后入库，带出处。

### 不做

- 无人值守破解 Pinterest / 绕登录 / 对抗反爬
- 大规模分布式爬虫
- 浏览器插件以外的第三方站点私有 API 逆向

Pinterest 类站点：粘贴看板 URL → `plugin_watch`。Chrome 插件按间隔**自动打开看板**（需已登录）、轻量滚动、入库新 Pin。Rust 轮询器跳过，不直连站点。

### 数据

```
sources
  id, name, kind,           -- rss | html_page | url_list | plugin_watch
  url,                      -- feed 或看板页
  interval_min,             -- 默认 360
  folder_id, tags_json,
  enabled, last_run_at, last_error,
  created_at

assets 增列
  source_kind   -- local | web | plugin | ai
  source_ref    -- sources.id 或 gen_jobs.id
```

### Adapter

| kind | 行为 |
|------|------|
| `rss` | 解析 RSS/Atom，抽 `<enclosure>` / `<media:content>` / 条目内图片 URL |
| `url_list` | 用户粘贴一批图片 URL，立即入库（手动） |
| `html_page` | GET 公开静态页，抽 `og:image` / `img[src]` / `srcset`（不登录、不跟分页，每次 ≤30，遵守 robots.txt） |
| `plugin_watch` | Chrome 插件盯梢。Pinterest：可后台打开看板、滚动收集新 Pin（每次最多 20 张新图），已见 Pin id 去重；其它站点仍要求标签保持打开。Rust 轮询器跳过，不直连站点 |

轮询：灵犀窗口进程内每 60 秒扫 `enabled` 源；关窗口即停。每次 tick 写 `pipeline_runs.kind=subscribe`。

### UI

侧栏「订阅」：添加源（RSS / 公开网页 / URL 列表 / **粘贴 Pinterest 看板即盯梢**）→ RSS/网页立即拉取 → 启用/暂停 → 上次错误。Pinterest 盯梢显示「自动盯梢中」和上次扫描摘要。素材详情显示 `source_kind=web|plugin` 与原帖 URL。

### 插件

右键单张，或「本页多选保存」。Pinterest 看板：订阅页粘贴 URL，或插件「盯梢此页」。插件每 2 分钟检查到期源；到期则打开（或复用）看板标签，滚动收集新 Pin 入库（`source_kind=plugin`，`source_ref=源 id`，出处为 Pin 页 URL）。未登录则写 last_error，等用户在该标签登录。

订阅源列表显示盯梢中/已暂停，以及上次扫描结果。

## 来源三：AI 生图

### 目标

对话式单张、以及一次 N 张批量。生成文件落入 inbox，再走同一入库管道。Prompt / 模型 / 尺寸写入笔记或独立字段，可检索。

### 客户端（类型 → 工厂 → env）

```
ImageGenRequest { prompt, n, size, negative?, seed? }
ImageGenResult  { files: [{path, mime}], provider, model, job_id }
```

| Provider | 何时 |
|----------|------|
| `mock` | `IMAGE_GEN_PROVIDER=mock`，或未配置 Key：写占位 PNG |
| `minimax` | MiniMax 文生图 `POST /v1/image_generation`，模型 `image-01`。CLIP 的 `AI_MOCK_MODE` **不**强制生图 Mock |
| `openai_compat` | OpenAI Images 或兼容网关，`IMAGE_GEN_BASE_URL` + `IMAGE_GEN_API_KEY` |

禁止硬编码 Key/URL。失败排查序：环境变量 → 网络 → 余额 → 日志 → Mock。

### 数据

```
gen_jobs
  id, prompt, n, size, provider, model,
  status,          -- running | generated | done | error
  folder_id,
  error, run_id, output_paths, created_at, finished_at
```

批量 = 一个 job、`n` 张；**生成**只落盘 `output_paths`（status=`generated`，不入库）；**入库**后 `source_kind=ai`，`source_ref=job.id`，`notes` 含 prompt。

### UI

「AI生图」面板：描述、张数（1–8）、尺寸、目标文件夹，以及常用 prompt 下拉。两个按钮：**生成**（预览）与 **入库**。选中已生成任务后入库；右侧可先看落盘图。

「prompt」页管理常用提示词（`prompt_presets`：名称 + 正文 + 可选参考图路径 + 分类），不负责生成。侧栏 prompt 下是三级分类；右侧预览窗关联图片，只链接原文件。点「挖掘」根据参考图逆向填入名称/提示词（复用生图 Key；无 Key 回退 mock）。

### DoD（来源三）

- [x] Mock：单张 + `n=4` 先 `generated` 再入库，`source_kind=ai`，prompt 可 FTS
- [x] 生成与入库拆开：生成不写 assets；入库才走 `import_paths_with`
- [x] 真实 Provider：MiniMax Key 已接通；失败有 `job_id` 日志且 job=`error`
- [x] 关闭 Key 时自动回退 Mock，不崩 UI
- [x] `verify.sh` 覆盖 Mock 单张/批量
- [x] `start.sh` / `stop.sh` 无需新常驻进程
