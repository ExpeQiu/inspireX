# 模块切分：素材管理 | AI 生图（2026-08-20）

架构：模板 1。一级入口在工具栏，不改入库管道。

## 结构

- **素材管理**：侧栏为全部素材、来源（外置卷 / 本地库 / 中转站 / 订阅源 / AI创作）、分类、标签。
- **AI 生图** 侧栏二级：`prompt`（常用提示词库）/ `AI生图`（填写描述、生成预览、入库）/ `AI作品集`（已入库）。路径：`/generate/prompt` `/generate` `/generate/created`。
- **设置** 钉在侧栏底部（两个模块都有）：`/settings` 配置文本 / 图片 / 视频 AI 服务（写入 `~/InspireX/ai-services.json`）。
- **prompt 三级分类**：点 prompt 旁 + 新建；`/generate/prompt/<id>` 只看该分类。删除分类不删 prompt。

切到「AI 生图」会重置侧栏二级项（任务从「全部任务」开始），并清掉上一页残留的 `status`。

## 路由

`appModule(mode)`：`generate` → AI 生图，其余 → 素材管理。从生图点「素材管理」恢复进入前的库内路径，默认 `/library`。

## 常用 prompt

`prompt_presets` 存名称、正文、可选参考图路径、分类，以及片库同步字段 `source_kind` / `source_uid`。`prompt_categories` 是 prompt 下的三级分类；从 VPromptStore 同步来的分类带 `source_key`，侧栏标「片库」，不能手动删。

进入 prompt 默认展示「参考图 + 提示词」缩略图。工具栏「同步片库」按 `source_uid` 增量 upsert（更新正文、补新条、删掉片库里已不存在的条目），不碰本地自建 prompt。未绑定且本机存在默认路径 `/Volumes/Lexar/git/12 highvalue/VPromptStore` 时，第一次打开 prompt 会自动同步一次。也可 `inspirex prompt sync`。

工具栏「添加」才打开编辑表单。点「选择图片」打开本机文件浏览；关联后点「挖掘」按图逆向填入名称和提示词（无 Key 时走 mock）。
