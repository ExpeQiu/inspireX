# InspireX CLI（模板 6）

命令 `inspirex`，目录 `cli/`。对接本机 `127.0.0.1:18765` 的 `/v1/invoke`。

## 命令

```
inspirex [--demo] [--format json] [-q|-v] <group> <action>
```

| group | action | 说明 |
|-------|--------|------|
| config | check / init | 配置 |
| — | status | 健康 + 库信息 |
| library | info | 库元数据 |
| asset | list / search / import / import-url | 素材 |
| folder | list / create | 文件夹 |
| tag | list / create | 标签 |
| source | list / pull | 订阅 |
| hub | status | 中转站 |

`--demo` 不访问后端。数据 stdout，日志 stderr。
