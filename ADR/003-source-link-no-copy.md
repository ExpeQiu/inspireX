# ADR-003：外置卷 / 本地库只展示来源，不复制原文件

> 状态：已采纳  
> 日期：2026-08-19  
> 模板：1（采集→管道→展示）

## 背景

侧栏「外置卷」「本地库」是已有文件的来源。原先外置卷可「加入本地库」，会把图片/视频复制进 `~/InspireX/Library/files`。这造成双份占用，且与「只浏览来源」的预期不符。

## 决策

| 来源 | 行为 |
|------|------|
| 外置卷 | 链接浏览 `/Volumes` 下外接存储，**不复制**原文件 |
| 本地库 | 用户用「追加文件夹」绑定**多个本机索引路径**（不默认扫家目录），链接浏览，**不复制**原文件；含 macOS「照片」图库 |
| 中转站 | 链接浏览用户绑定的 **云同步文件夹**；「存入」是复制进该文件夹，**不入灵犀库**。同步由 iCloud/网盘完成（见 ADR-005） |
| 订阅源 / 插件 / AI 生图 | 仍入库（远程或新生成的内容本地没有原件） |

缩略图可写在库目录的缓存里，不算原文件副本。

## 后果

- 正：外接盘与本机相册不占双倍空间；拔盘后原件仍在原处。
- 负：外置卷/本地库不做 CLIP 入库索引；「全部素材」只含订阅、插件、生图。  
- 「照片」图库若开启 iCloud 优化存储，原片可能不在本机，此时展示图库内预览 JPEG，仍不复制到灵犀库。
