# ADR-004：自定义文件夹为虚拟索引

> 状态：已采纳  
> 日期：2026-08-19  
> 模板：1（采集→管道→展示）

## 背景

侧栏「分类 +」需要用户自建相册，并把已选图片放进去。外置卷 / 本地库按 ADR-003 只链接浏览、不复制原文件。

## 决策

- 侧栏「分类」与「来源」同级，不随选中的外置卷 / 本地库 / 订阅 / 生图而隐藏。
- 分类是**项目内索引**：记录在灵犀 SQLite（`folders` + `folder_items`），**不在来源磁盘 mkdir**。
- `folder_items` 只存 `asset` id 或文件 `path`；勾选后点旁 `+` 写入索引，不复制、不移动原文件。
- 删除分类只删灵犀记录，原文件保留。

## 后果

- 正：外接盘与本机相册可按主题归类，不占双份空间。
- 负：拔盘后路径项可能暂时无法预览，插回后仍可打开。
