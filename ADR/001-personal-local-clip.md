# ADR-001：个人全本地 + 本地 CLIP

> 状态：已采纳  
> 日期：2026-07-26  
> 模板：1（采集→管道→展示，裁剪为单机）

## 背景

InspireX（灵犀）对标 Eagle 类视觉素材库。已确认：**个人使用、全本地、AI 用本地 CLIP**。不做云同步与协作。

## 决策

| 项 | 选择 |
|----|------|
| 架构模板 | **模板 1**（采集→管道→展示）；参考 `/Volumes/Lexar/git/03T/Uni-SIM` 的管道思维，**不**复制多 CLI monorepo |
| 运行形态 | 单机桌面 **Tauri 2 + React** |
| 数据 | **SQLite + FTS5**；原文件落用户库目录 |
| 云 | **无**（无 PostgreSQL / S3 / 账号） |
| AI | **本地 CLIP**；开发默认 `AI_MOCK_MODE=true`（确定性伪向量）跑通闭环 |
| 智能层 | **按需批处理**（入库异步索引），非常驻烧算力 |
| 首发平台 | macOS（Apple Silicon 优先） |

## 为何不用其他模板

- 2/4：无场景合同 / Skill 中台需求  
- 3：无高并行 Agent  
- 5：产品不是工作流画布  
- 6：主交付是桌面 GUI，不是 CLI 作业（可后续加采集 CLI）

## 必答（模板 1 裁剪）

1. **Monorepo？** 否，单仓单桌面应用。  
2. **双写？** 否；业务表即真相，向量表同库旁路。  
3. **编排中枢？** 应用内 `pipeline` 模块，无独立 :8080 服务。  
4. **默认运行时？** 本机 `tauri dev` / 安装包；无 Docker 依赖。  
5. **智能层？** 入库队列按需；Mock 可关模型。

## 后果

- 正：隐私、离线、实现面可控。  
- 负：无跨设备；CLIP 模型体积与首启下载需产品化。  
- 后续：浏览器插件采集、真实 CLIP 权重接入、Eagle 迁移。
