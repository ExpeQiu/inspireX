# ADR-005：中转站绑定云同步文件夹（不自建云）

> 状态：已采纳  
> 日期：2026-08-19  
> 模板：1（采集→管道→展示）

## 背景

侧栏已有「外置卷」「本地库」链接浏览。需要多端共享一批图片，但不引入账号、对象存储或自建同步。

## 决策

| 项 | 选择 |
|----|------|
| 入口 | 侧栏「本地库」下方新增 **中转站** |
| 绑定 | 用户指定本机上已由 iCloud / Dropbox / OneDrive 等同步的文件夹 |
| 存入 | 把图片 **复制进该文件夹**（不入灵犀 `Library/files`） |
| 同步 | **由云盘客户端完成**；灵犀只浏览与复制 |
| 浏览 | 与外置卷 / 本地库相同：链接展示原文件，缩略图可走库缓存 |

未绑定前只展示绑定引导（可一键用「iCloud 云盘/InspireX-Hub」等建议路径）。绑定路径写入 `~/InspireX/hub-root`，可用 `INSPIREX_HUB_ROOT` 覆盖。

## 为何不用其他做法

- 不改 ADR-001 做账号云同步：个人全本地边界不变。
- 不把中转站文件再复制进素材库：与 ADR-003 一致，避免双份占用。
- 不实现自研差量同步：云盘已解决冲突与多端。

## 后果

- 正：多台电脑绑定各自本地的同一云盘目录即可共享；实现面小。
- 负：依赖用户已安装的云盘；未登录 / 优化存储时原片可能尚未在本机。
